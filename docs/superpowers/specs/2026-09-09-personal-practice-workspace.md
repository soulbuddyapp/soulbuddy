# Personal Practice Workspace

## Goal

Make the Goals destination a clear home for a person's own spiritual work.

## Experience

The screen title is **My practice**. Its first section, **What you've created**, combines the person's active Goals and private Prayers in one compact list. It defaults to recently updated items, with one filter control for All, Goals, or Prayers and one sort control for Recent, A–Z, or Goal priority.

The screen has one clear **Create** control. It opens Goal, Prayer, and Meditation choices. Goal opens the existing Goal starter, Prayer opens the private prayer flow, and Meditation opens the meditation experience. Prayer library browsing remains available as a secondary action in the Create sheet, not as a competing top-level button.

Goal rows retain their existing status and priority controls when the Goal filter and Goal priority sort are active. Prayer rows open their saved personal prayer. Empty and partial-loading states explain only what is unavailable and leave the available creation choices usable.

## Boundaries

This changes presentation and local list ordering only. It does not change Goal persistence, Prayer persistence, the prayer library, meditation data, or routes.

## Validation

Widget coverage proves that private Goals and Prayers appear in one list, filters hide the other type, sort changes the visible order, each Create action targets its existing route, and large text remains usable.
